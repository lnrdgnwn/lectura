# Lectura - Platform Baca Online 📖

Lectura adalah platform baca online yang dirancang untuk memudahkan pengguna dalam menemukan dan menikmati berbagai jenis bacaan. Meskipun deskripsi awal terbatas, platform ini bertujuan untuk menyediakan pengalaman membaca yang menyenangkan dan interaktif.

## Fitur Utama ✨

*   **Koleksi Novel yang Luas 📚:** Temukan berbagai novel dari berbagai genre, memudahkan Anda untuk menemukan bacaan favorit Anda.
*   **Bookmark & Riwayat Baca 🔖:** Simpan bab yang sedang Anda baca dan lacak riwayat bacaan Anda untuk melanjutkan dari tempat Anda terakhir berhenti.
*   **Rekomendasi Genre yang Dipersonalisasi 🎭:** Dapatkan rekomendasi bacaan berdasarkan preferensi genre Anda untuk menemukan judul baru yang menarik.

## Tech Stack 🛠️

*   **Bahasa Pemrograman:** JavaScript, Go
*   **Framework:** Node.js (kemungkinan menggunakan Express.js untuk backend), Go (untuk sebagian backend)
*   **Database:** (Tidak disebutkan, kemungkinan menggunakan database seperti PostgreSQL atau MongoDB)

## Instalasi & Menjalankan 🚀

1.  Clone repositori:
    ```bash
    git clone https://github.com/lnrdgnwn/lectura
    ```
2.  Masuk ke direktori:
    ```bash
    cd lectura
    ```
3.  Install dependensi (Backend - Node.js):
    ```bash
    cd backend
    npm install
    ```
4.  Jalankan proyek (Backend - Node.js):
    ```bash
    cd backend
    npm start
    ```
    Atau, jika menggunakan `nodemon`:
    ```bash
    npm run dev
    ```
